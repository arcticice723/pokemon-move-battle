# Nexus

Nexus is a multiplayer game hub built with Node.js, Express, and Socket.IO.

## Games
- Pokémon Move Battle: take turns entering unique Pokémon moves.
- Who Am I?: multiplayer fictional-character guessing with genre and franchise filters.

## Run locally
```bash
npm install
npm start
```
The server listens on `PORT` or port 3000 by default.

## Deploy on Render
Create a Web Service connected to this repository. The included `render.yaml` uses `npm install` and `npm start`.
